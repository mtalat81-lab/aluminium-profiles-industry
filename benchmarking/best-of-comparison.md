## Benchmarking Methodology

### Definition: "Best-Of"

The "best-of" represents the highest performing score in each metric category across all evaluated suppliers and competitors.

```
Best-Of Score = MAX(All Supplier Scores in Category)
```

### Variance Formula

```
Variance % = ((Supplier Score - Best-Of Score) / Best-Of Score) × 100
```

### Interpretation Guide

| Variance Range | Meaning | Status |
|----------------|---------|--------|
| > 5% | Exceeding best-of | ⭐ |
| 0% to 5% | At best-of standard | ✅ |
| -1% to -10% | Minor gap | ✅ |
| -11% to -20% | Moderate gap | ⚠️ |
| < -20% | Significant gap | ❌ |
